# DevTrack

## プロジェクト概要

開発チーム向けのプロジェクト・タスク管理Webアプリケーション。

## 開発目的

実務を想定し、要件定義から設計、実装、テスト、CI/CD、AWSへのデプロイ、監視まで一貫したWebアプリケーション開発を経験する。

## 想定ユーザー

### プロジェクト管理者

プロジェクトやメンバー、タスクを管理するユーザー。

### プロジェクトメンバー

プロジェクトに参加し、担当タスクの確認や進捗更新を行うユーザー。
