# TaskMagagementアプリケーションプロジェクト

## プロジェクト概要

開発チーム向けのプロジェクト・タスク管理Webアプリケーション。

## 開発目的

実務を想定し、要件定義から設計、実装、テスト、CI/CD、AWSへのデプロイ、監視まで一貫したWebアプリケーション開発を経験する。

## プロダクト目的

プロジェクト内のタスク、担当者、期限、進捗状況を一元管理し、
チーム内で「誰が・何を・いつまでに対応するのか」を明確にする。

# 想定ユーザー

プロジェクト管理者、プロジェクトメンバー

## プロジェクト管理者

プロジェクトやメンバー、タスクを管理するユーザー。

## プロジェクトメンバー

プロジェクトに参加し、担当タスクの確認や進捗更新を行うユーザー。

# 権限管理

## プロジェクト管理者

- プロジェクトメンバーの割り振り、プロジェクトの期限の設定、担当者の割り振りなどができる

## プロジェクトメンバー

- タスクの設定ができる

# MVP機能要件

## ユーザー管理

- ユーザーを作成できる
- ユーザー作成時に権限を設定できる
  - プロジェクト管理者
  - プロジェクトメンバー
- ユーザー情報を確認できる

## 認証

- ログインできる
- ログアウトできる
- 未ログインユーザーは認証が必要な画面・APIにアクセスできない

## プロジェクト管理

- プロジェクト管理者はプロジェクトを作成できる
- プロジェクト名を設定できる
- プロジェクトの概要を設定できる
- プロジェクトの期限を設定できる
- プロジェクト一覧を確認できる
- プロジェクト詳細を確認できる

## タスク管理

- プロジェクト内にタスクを作成できる
- タスク一覧を確認できる
- タスク詳細を確認できる
- タスクを編集できる
- タスクを削除できる

### タスク情報

タスクには以下の情報を設定できる。

- タイトル
- 説明
- 担当者
- 期限
- 優先度
- ステータス
- 作成者
- 作成日時
- 更新日時

## 担当者管理

- タスクに担当者を設定できる
- 担当者にはプロジェクトに所属しているメンバーのみ設定できる
- タスクの担当者を変更できる

## ステータス管理

タスクには以下のステータスを設定できる。

- TODO
  - 未着手
- PROGRESS
  - 作業中
- REVIEW
  - レビュー中
- DONE
  - 完了

- タスクのステータスを変更できる
- プロジェクトメンバーは担当タスクの進捗を更新できる

## 権限管理

### プロジェクト管理者

- プロジェクトを作成・編集できる
- プロジェクトの期限を設定できる
- プロジェクトメンバーを追加・削除できる
- タスクを作成・編集・削除できる
- タスクの担当者を設定・変更できる

### プロジェクトメンバー

- 所属しているプロジェクトを閲覧できる
- プロジェクト内のタスクを閲覧できる
- タスクを作成できる
- 担当タスクを編集できる
- 担当タスクのステータスを変更できる
